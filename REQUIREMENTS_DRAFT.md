# Mountain Kids Game — MVP Requirements

## Goal
A fun, low-poly 3D browser game for kids ages 8-12.

## Audience
- Age 8-12
- Casual, just-for-fun gameplay
- Low processing power machines

## MVP Scope (Phase 1)
| Feature | Status |
|---------|--------|
| Single screen | ✅ In |
| Mountain map | ✅ In |
| Single player | ✅ In |
| Low-poly 3D models | ✅ In |
| Small render target | ✅ In |
| Missiles | ❌ Cut |
| Nitro/boost | ❌ Cut |
| Multiple maps | ❌ Cut |
| Multiplayer | ❌ Cut |
| Saved data / persistence | ❌ Cut |

## Game Concept (To Be Defined)
Vehicle type and core loop to be specified. Was originally planned with missiles + nitro suggesting aerial or racing combat; without those, likely: mountain exploration, casual flying, or scenic driving.

## Non-Functional
- Runs in browser (no install)
- Low GPU/CPU requirement
- No backend persistence
- Free tier hosting
